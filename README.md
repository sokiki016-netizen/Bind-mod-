# Bind Mod — бинды команд + мини-HUD для Minecraft 1.21.4 (Fabric)

Клиентский мод: вешаешь любую команду (или сообщение в чат) на любую клавишу или кнопку мыши,
плюс небольшой HUD с прочностью брони и модуль анти-АФК.

Нажал **Правый Alt** → открылось стеклянное меню → добавил команду → нажал клавишу → готово.

Ничего ставить на сервер не нужно — работает на любом сервере. Читерских функций нет:
никаких killaura/esp/x-ray, только бинды, HUD и анти-AFK.

## Установка

1. Скачай `bindmod-1.1.0.jar` из [Releases](../../releases).
2. Нужны **Fabric Loader 0.16+** и **Fabric API** для **Minecraft 1.21.4**.
3. Положи jar в `.minecraft/mods`.

## Меню (Правый Alt)

Тёмное «liquid glass» меню с боковыми вкладками:

| Вкладка | Что внутри |
|---|---|
| **БИНДЫ** | список биндов, `+ Добавить бинд`, клик по строке — изменить, `×` — удалить, колесо мыши — прокрутка |
| **МОДУЛИ** | тумблеры «Прочность брони (HUD)», «Анти-АФК», позиция HUD, интервал и действие анти-АФК |
| **НАСТРОЙКИ** | клавиша меню, удаление всех биндов |

Esc или повторное нажатие клавиши меню — закрыть.

## Бинды

* Команда с `/` уходит как команда (`/spawn`, `/home`, `/kit pvp`), без `/` — как сообщение в чат.
* Можно биндить кнопки мыши (например, боковые).
* Если клавиша занята — старый бинд заменяется, в чат приходит уведомление.
* Бинды срабатывают только когда открыт мир и нет открытых экранов. Клавиши, которые в ванили
  сами что-то открывают (`E`, `T`, `Esc`), лучше не использовать.

## HUD прочности брони

Панель с иконками надетой брони и процентом оставшейся прочности
(зелёный → жёлтый → красный). Позиция — 4 угла экрана, включается/выключается во вкладке **МОДУЛИ**.

## Анти-АФК

Раз в N секунд (по умолчанию 60) клиент сам очень коротко нажимает «присесть» или «прыжок» —
игра отправляет обычный пакет движения, и сервер не кикает за AFK. Настраивается интервал (5–300 с)
и действие. На сервер ничего не устанавливается, поведение неотличимо от живого игрока.

## Конфиг

`.minecraft/config/bindmod.json`

```json
{
  "menuKey": "key:346",
  "binds": [
    { "key": "key:82", "command": "/spawn" },
    { "key": "mouse:3", "command": "/home" }
  ],
  "hud": { "armorDurability": true, "corner": 0 },
  "antiAfk": { "enabled": true, "intervalSeconds": 60, "mode": 0 }
}
```

`key:<glfw code>` — клавиша, `mouse:<button>` — кнопка мыши. `corner`: 0 — слева сверху,
1 — справа сверху, 2 — слева снизу, 3 — справа снизу. `mode`: 0 — присесть, 1 — прыжок.

## Сборка из исходников

```bash
./gradlew build
# готовый jar: build/libs/bindmod-1.1.0.jar
```

Нужен JDK **25** (Gradle 9.8 + Loom 1.19 требуют JVM 25), сам мод компилируется под Java 21.
CI (`.github/workflows/build.yml`) собирает jar на каждый пуш и сам выкладывает его в Releases.
