# Bind Mod — бинды команд для Minecraft 1.21.4 (Fabric)

Клиентский мод: вешаешь любую команду (или сообщение в чат) на любую клавишу или кнопку мыши.
Нажал **Правый Alt** → меню → добавил команду → нажал клавишу → готово.

Ничего ставить на сервер не нужно — работает на любом сервере, включая ванильные.

## Установка

1. Скачай `bindmod-1.0.0.jar` из раздела [Releases](../../releases).
2. Нужны **Fabric Loader 0.16+** и **Fabric API** для **Minecraft 1.21.4**.
3. Положи jar в `.minecraft/mods`.

## Как пользоваться

| Действие | Что делать |
|---|---|
| Открыть меню биндов | **Правый Alt** (меняется в самом меню) |
| Добавить бинд | «+ Добавить бинд» → ввести команду → «Далее: нажать клавишу» → нажать нужную клавишу/кнопку мыши |
| Изменить бинд | нажать на клавишу или на текст команды в списке |
| Удалить бинд | кнопка **X** |
| Закрыть меню | **Esc** или снова Правый Alt |

* Команда начинается с `/` → уйдёт как команда (`/spawn`, `/home`, `/kit pvp` …).
* Без `/` → уйдёт как обычное сообщение в чат.
* Можно биндить и кнопки мыши (например, боковые кнопки).
* Если клавиша уже занята — старый бинд заменяется, в чат придёт уведомление.
* Бинды срабатывают только когда открыт мир и не открыт никакой экран. Клавиши, которые в ванили
  сами что-то открывают (`E`, `T`, `Esc`), лучше не использовать — они откроют свой экран.

## Конфиг

Всё хранится в `.minecraft/config/bindmod.json`:

```json
{
  "menuKey": "key:346",
  "binds": [
    { "key": "key:82", "command": "/spawn" },
    { "key": "mouse:3", "command": "/home" }
  ]
}
```

`key:<glfw code>` — клавиша, `mouse:<button>` — кнопка мыши. Правый Alt — `346`, F — `82`.

## Сборка из исходников

```bash
./gradlew build
# готовый jar: build/libs/bindmod-1.0.0.jar
```

Нужен JDK **25** (Gradle 9.8 + Loom 1.19 требуют JVM 25), сам мод компилируется под Java 21.
